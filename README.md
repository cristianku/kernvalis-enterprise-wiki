# Kernvalis Corporate Knowledge Base

Kernvalis Industries, Inc. is a fictional US industrial automation, robotics and electronics company founded in 2005 and headquartered in Austin, Texas. This repository is a synthetic enterprise documentation corpus for knowledge management research and AI agent benchmarking. All company facts, people, incidents and records are fictional; nothing is an assertion about a real business.

## Corpus goals

- 2,500 employees, 12 sites, 15 departments, 40 information systems.
- Approximately 200 business processes, 1,500 business rules and 3,000 substantive Markdown documents.
- Historical coverage: 2005–2026; reference snapshot: 2026-11-26.
- English-language documentation, portable between GitHub and GitLab.
- Cross-document dependencies, exceptions, superseded policies, historical decisions and realistic missing knowledge.
- Independent of any particular retrieval engine or database.

The corpus now contains over 3,000 Markdown knowledge pages, including deterministic synthetic operational records across commercial, service, manufacturing, procurement and IT domains. These records use shared identifiers and cross-document references; some document families intentionally share standard enterprise record structures. This is a synthetic benchmark dataset, not a corpus of real-world corporate prose. The six-digit Git revision and the exact wiki file inventory should be recorded per benchmark. No application source code is required to answer the enterprise questions. Benchmark answers and generation metadata should remain outside the ingested wiki to avoid leakage.
