# Kernvalis Corporate Knowledge Base

Kernvalis Industries, Inc. is a fictional American multinational industrial automation, robotics and electronics company founded in 2005 and headquartered in Austin, Texas. Its November 26, 2026 enterprise baseline has 2,500 employees, 12 sites, 15 departments, 40 business applications and a USD 850 million approved annual net revenue plan.

All organizations, people, products, amounts and events described here are synthetic. They are not assertions about real businesses or individuals.

## Dataset snapshot

The current `wiki/` corpus contains **17,097 Markdown documents**, approximately **13.73 MB** of uncompressed source text. It covers the corporate history from 2005 through 2026 and includes five fiscal years of financial reporting (2022–2026).

## Benchmark use

Clone the repository and pin the full Git commit SHA. Import and index only `wiki/`. Both the Markdown baseline and an alternative knowledge database must start from the same files at the same revision. Answers should be grounded in the enterprise corpus, not in external knowledge or application source code.

The corpus contains policies, procedures, historical information, business facts, records, approvals, exceptions, meeting minutes and interconnected evidence. The reference date is 2026-11-26. A planned action, historical decision, expired approval and completed transaction are different states.

This corpus is generated synthetic data, not manually authored enterprise prose throughout. Many record families have standardized structures and systematically varied business facts. The file count and size were verified against the Git tree; a complete semantic audit, link audit and independent benchmark evaluation remain necessary. Do not report benchmark findings until measured.

Keep authoring instructions, question generation, expected answers and benchmark traces outside the imported wiki. See [documentation specification](authoring/specification.md).
