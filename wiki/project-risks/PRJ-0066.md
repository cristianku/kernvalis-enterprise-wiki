# Project risk register — PRJ-0066

Review date: 2023-06-22. Project: [PRJ-0066](../projects/PRJ-0066.md). Risk owner: SW site team. Scope: software release controls.

### R1 — evidence gap

Released version, hardware revision, regression evidence and rollback remain independent. Impact: medium. Likelihood: low. Proposed mitigation: compare operational records against the authoritative control before releasing the affected workflow. Residual risk: medium. The owner accepted monitoring with a scheduled review.

### R2 — implementation drift

A newer firmware version is not necessarily eligible for every hardware revision. Mitigation: preserve scope, revision, owner and execution evidence. Test the operational handover with the receiving team. Open until the delivery report includes verification.

### R3 — benefits overstatement

The 80% target is a forecast. Use the actual measured result in the benefits review, not the target. No record establishes avoided financial losses.
