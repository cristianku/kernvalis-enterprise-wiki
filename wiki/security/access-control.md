# Access control (SEC-01)

Owner: Security and IT. Effective: 2025-01-01. Status: active at 2026-11-26.

## Requirements

Privileged access requires manager and Security approval, individual identity and MFA. Break-glass access expires after four hours. Review privileged access quarterly.

## Evidence

Record the affected entity, decision date, applicable rule, evidence and approving role. Approval in a different process does not override these requirements.
