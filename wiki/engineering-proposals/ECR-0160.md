# Engineering change request ECR-0160 — Communication timeout

Opened 2026-08-20. Product [VM-190](../products/VM-190.md); current master revision A, proposed revision B. This change request is a proposal or restricted pilot; it does not replace the current released product master. Objective: Improve recovery after transient network loss. Impact: Timeout changes affect integration behavior and compatibility.

Safety-impact classification: safety-related. Affected production and service populations must be determined by controlled serial effectivity, not merely product family. The sponsor requested a controlled pilot before considering general production release.
